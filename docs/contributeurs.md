## Contributions au dépôt

Les contributions apportées directement au dépôt (fiches, corrections, schémas) sont
listées automatiquement par GitHub :
[page Contributors du dépôt](https://github.com/Institut-du-Numerique-Responsable/BP-AIR/graphs/contributors).

Chaque fiche indique par ailleurs ses `contributeurs` et `reviewers` dans son entête.

## Citer ce travail

Les métadonnées de citation sont maintenues dans le fichier
[`CITATION.cff`](https://github.com/Institut-du-Numerique-Responsable/BP-AIR/blob/main/CITATION.cff)
à la racine du dépôt.

## Une correction ?

Nom, organisation ou rôle inexact ? [Ouvrez une issue](https://github.com/Institut-du-Numerique-Responsable/BP-AIR/issues/new)
ou proposez directement une Pull Request sur ce fichier.
