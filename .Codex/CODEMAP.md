# BP-AIR code map

- `mkdocs.yml` — MkDocs Material site configuration, navigation, theme, extensions and plugins.
- `docs/index.md` — public landing page and map of the best-practice framework.
- `docs/guide-unifie.md` — consolidated narrative guide covering the whole framework.
- `docs/fiches/*.md` — individual best-practice sheets grouped by governance, measurement, design, infrastructure, value and compliance.
- `docs/contributeurs.md` — contributors and acknowledgements.
- `docs/assets/` — diagrams, logos, social preview and site-specific CSS.
- `README.md` — repository overview, framework structure and contributor-facing technical notes.
- `TEMPLATE-fiche.md` — template for new best-practice sheets.
- `CONTRIBUTING.md` — contribution workflow and writing conventions.
- `SECURITY.md` — vulnerability reporting policy.
- `hooks/llms.py` — MkDocs hook that generates LLM-oriented text output from the documentation.
- `overrides/` — MkDocs theme overrides.
- `requirements.txt` — Python dependencies for building the documentation site.
